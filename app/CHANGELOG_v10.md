# v10 更新说明（在 v9 修复版基础上新增的 12 项功能）

## 1. 搜索/筛选过滤（routes/home.py）
- 搜索结果和标签筛选结果只显示「已上架」商品，待审核/已驳回一律不出现。
- 默认首页仍显示卖家自己的待审核商品（已驳回的自己的商品也不再显示）。

## 2. 私信越权校验（routes/messages.py）
- 新增 `_user_exists` / `_has_conversation` 校验。
- 对话页与发消息接口：不能和自己聊天（403）；对方不存在（404）；
  两人无历史消息且未从商品页携 product_id 进入的，视为越权（403）。

## 3. 求购按钮文案
- 求购商品的按钮统一为「🤝 立即出售」：首页卡片（templates/home/_card.html）、
  首页详情弹窗（按 type 动态切换）、收藏页。

## 4. 发布成功提示
- 发布成功后 `flash('发布成功，等待审核')`，首页顶部渲染 flash 消息。

## 5. 首页「加载更多」分页
- 首页底部加「加载更多」按钮；点击通过 `/?page=N&ajax=1` 拉取下一页三个分组的
  卡片 HTML 片段并追加；全部加载完显示「没有更多了」。
- 卡片抽取为公共宏 `templates/home/_card.html`，首页与 Ajax 片段
  `templates/home/_cards_ajax.html` 共用，保证样式逻辑一致。

## 6. 个人中心「我发布的商品」管理
- profile 页新增表格：商品名称 / 价格 / 状态 / 详情（弹窗）/ 删除。
- 顶部状态下拉筛选（全部/待审核/已上架/已驳回，前端过滤）。
- 删除权限放开：卖家本人可删除任何状态的商品（routes/admin.py delete），
  表单支持 `next` 站内回跳地址（防开放重定向）。
- 已售出商品删除后，买家订单显示「商品已删除」（orders 原有 LEFT JOIN 逻辑已支持）。

## 7. 管理员商品 Tab 筛选
- /admin 支持 `status=pending|approved|rejected`，商品管理面板顶部加
  全部/待审核/已上架/已驳回 Tab（带数量角标），搜索与分页保持状态参数。

## 8. 图表样式统一
- 个人中心图表统一为同高度（340px）卡片、栅格均匀分布，
  Chart.js 统一 `maintainAspectRatio:false`。
  注：个人中心实际只有 3 张图（月度交易、星级分布、全校信用分布），已全部统一。

## 9. 收藏页操作按钮
- 每张收藏卡片新增：📄 详情（跳首页详情弹窗）、💬 在线沟通（带 product_id）、
  🛒 立即购买 / 🤝 立即出售（按商品类型切换，跳首页自动打开下单弹窗）。
- 自己的收藏商品不显示沟通/购买按钮；已售出不显示购买按钮。

## 10. 私信带商品卡片
- 首页三个分组卡片的「私信」、详情弹窗「发消息」、收藏页「在线沟通」
  均携带 `?product_id=N`，进入私信自动落商品卡片消息。

## 11. 管理员数据看板
- 统计卡片统一 min-height 92px、grid 拉伸对齐、最小列宽 180px。

## 12. 全站响应式
- 全部模板补齐 viewport meta（首页/个人中心/管理后台/消息/发布/评价/登录/反馈/禁言页等）。
- 桌面端（≥992px）卡片与头部按钮加大；手机端（<768px）按钮加大触控面积（min-height 38px）、
  头部竖排、Tab 均分；平板端（768~991px）保持原样。

## 部署
```
tar -xzf fix_patch_v10.tar.gz -C /home/ubuntu/my_dev
sudo systemctl restart secondhand
```
验证：`grep -c "加载更多" /home/ubuntu/my_dev/app/templates/home/index.html` 应大于 0。
