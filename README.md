# 校园二手交易平台 🛒

> 基于 Flask + 云服务器部署的半封闭社区 C2C 二手交易系统，三轮机制迭代，NPS 93。

## 📋 项目简介

面向高校学生的二手交易平台，支持商品发布、浏览、搜索、下单、聊天等核心功能。采用 Flask 后端 + 前端模板渲染架构，已部署至云服务器上线运行。

## ✨ 核心功能

- **商品管理**：发布、编辑、下架二手商品
- **搜索筛选**：按分类、价格、关键词搜索商品
- **交易流程**：下单、确认收货、评价体系
- **用户系统**：注册登录、个人中心、信用评分
- **消息通知**：站内信、交易状态提醒

## 🛠 技术栈

- **后端**：Python / Flask
- **前端**：HTML / CSS / JavaScript / Jinja2 模板
- **数据库**：SQLite（开发）/ PostgreSQL（生产）
- **部署**：云服务器（Linux + Nginx + Gunicorn）
- **其他**：RESTful API、会话管理

## 🚀 快速开始

### 本地运行

```bash
# 解压代码补丁包
tar -xzf fix_patch_v15_no_confirm_code.tar.gz

# 安装依赖
pip install -r requirements.txt

# 启动开发服务器
python app.py
```

访问 http://localhost:5000

### 线上访问

平台已部署至云服务器，可直接访问使用。
