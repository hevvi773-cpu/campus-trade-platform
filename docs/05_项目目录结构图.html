v15 代码结构 · 服务部署路径 /home/ubuntu/my_dev/app/
/home/ubuntu/my_dev/app/ ← 应用根目录（secondhand.service WorkingDirectory）
├── app_v3.py 主应用：Flask app 实例、init_db() 建表、路由注册、常量导出、ensure_schema()
├── wsgi.py gunicorn 入口：from app_v3 import app as application
├── .env 环境配置：数据库连接、admin 密码、密钥等（部署时 --exclude 保留）
├── requirements.txt Python 依赖：Flask、gunicorn、pymysql 等
├── CHANGELOG_v14.md v14 清理变更记录
├── CHANGELOG_v15.md v15 移除确认码变更记录
│
├── routes/ 路由层（8个模块，每个负责一组页面/API）
│ ├── auth.py 登录 / 注册 / 登出 / 填写学号 / 密码修改
│ ├── home.py 首页 / 商品列表 / 搜索 / 浏览记录
│ ├── products.py 商品发布 / 详情 API / 标记已售 / 评价提交 / 确认码(已移除)
│ ├── orders.py 订单列表 / 发起购买 / 卖家确认 / 买家取消
│ ├── messages.py 私信列表 / 对话详情 / 发送消息 / 未读计数
│ ├── favorites.py 收藏列表 / 添加收藏 / 取消收藏
│ ├── profile.py 个人中心 / 我发布的 / 我买到的 / 账号设置
│ └── admin.py 管理后台：商品审核 / 用户封禁 / 反馈处理 / 日志查看
│
├── services/ 业务逻辑层（路由调用，封装复杂业务）
│ ├── message_service.py 私信业务：消息列表、未读计数、发送、兼容旧表结构
│ ├── order_service.py 订单业务：创建订单、确认交易、取消订单
│ ├── constants.py 常量定义：PRODUCT_TAGS、STATUS_MAP、SOLD_STATUS_MAP、TYPE_MAP
│ └── db_helpers.py 数据库辅助：连接管理、查询封装、日志记录
│
├── templates/ Jinja2 模板层（HTML 页面）
│ ├── home/ index.html（首页+商品列表+详情弹窗）
│ ├── auth/ login.html / register.html / student_id.html
│ ├── products/ publish.html / detail.html
│ ├── orders/ orders.html（订单列表+确认/取消操作）
│ ├── messages/ messages.html / chat.html
│ ├── profile/ profile.html / settings.html
│ └── admin/ admin.html / audit.html / users.html / feedback.html
│
└── static/ 静态资源
├── css/ 样式文件
├── js/ 前端脚本（首页交互、详情弹窗、评价提交等）
└── uploads/ 用户上传：desc/（商品图）、contact/（联系方式图）

注释说明
📂 架构分层：routes（路由层，接收请求）→ services（业务层，处理逻辑）→ 数据库（pymysql 直接操作）。templates 负责页面渲染，static 存放静态资源。
🚀 启动流程：systemd → gunicorn（wsgi:application）→ wsgi.py → app_v3.py（ensure_schema 建表 + 注册 8 个路由模块）→ 监听 127.0.0.1:8000。
