用户角色权限图 · 校园二手交易平台
三级权限体系：游客(guest) → 学生(student) → 管理员(admin)

👤 游客 (guest)

未登录用户，仅可浏览公开内容。users.role 字段不存在，由 session 判断。

🎓 学生 (student)

注册并登录的普通用户，users.role='student'。可进行完整交易流程。

🛡️ 管理员 (admin)

users.role='admin'，初始账号 admin（密码从 .env 读取）。拥有全部权限 + 后台管理。

🔐 权限实现方式：通过 session['username'] 判断是否登录，session['identity']（或 users.role）判断角色。路由层用装饰器或条件判断拦截未授权访问，如 admin 路由校验 `session.get('identity') == 'admin'`。
⚠️ 封禁机制：users.ban_until 字段记录封禁截止时间，被封禁用户登录时校验，封禁期间无法发布商品、购买等操作。
⏰ 超时自动审核：商品 pending 超过 24 小时自动通过（auto_approve_stale），减轻管理员审核负担，保证普通用户发布体验。
