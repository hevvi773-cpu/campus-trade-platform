## 校园二手交易平台 | 全栈开发 + 产品设计 | 2026.06 - 至今

**项目链接**：http://106.53.27.244（线上可体验）｜ GitHub：github.com/hevvi773-cpu/campus-trade-platform

面向高校学生的 C2C 二手交易系统，解决校园二手信息分散在 QQ 群 / 校园频道 / 表白墙、商品状态不透明、各渠道检索能力不一的痛点，已部署公网上线。

- **独立负责后端 + 网页端开发**：基于 Flask + MySQL 全栈实现，从单文件 7619 行重构为 9 路由 + 11 服务的模块化架构，累计 15 个版本迭代，每个版本附 CHANGELOG
- **完整交易闭环**：实现商品发布审核（24h 自动过审兜底）、订单交易（`SELECT ... FOR UPDATE` 行级锁防并发抢单与超卖）、站内私信（商品上下文卡片）、评价体系（买家评价卖家，1-5 星）、管理后台数据看板，共 35 条路由、11 张数据表
- **工程质量与安全**：修复 P0 级 `onclick` 引号冲突 bug（管理后台按钮全部失效）、首页 500 热修、confirm_code 越权漏洞；管理后台统计 SQL 从 35 次优化至 11 次；全站 CSRF 防护 + 登录限流（5 次锁 10 分钟）+ 三级权限体系
- **产品文档**：独立撰写实现对齐型 PRD V1.3（106KB），逆向整理 13 个历史版本，含 11 张表 DDL、API 契约、隐私合规方案、20 条回归清单、DEV-001~013 遗留问题
- **真实数据**：单人多账号全流程交叉验证，24 用户、51 件商品、17 件已售出（17 笔完整交易闭环），跑通注册→发布→审核→下单→确认→评价完整流程

**技术栈**：Python / Flask / MySQL / Jinja2 / Bootstrap 5 / Chart.js / gunicorn / systemd
